删除项目　
删除后该项目不再出现在下拉列表。为防误删，项目目录会被**整体移入** 程序目录下的「_项目回收站」，需要时把该目录移回「项目」即可恢复； 同时会取消该项目未完成的队列任务。
数据重置　
勾选要清空的内容。执行前会把将被删除的内容备份到项目目录下的 「_重置备份_时间戳」，误删可从那里取回；「招标文件」不会被清理。

项目信息

点「保存」后，服务端会建立：{项目名称}\ 投标文件、招标文件、评委打分、复核报告（四个子目录），并写入 项目信息.json。

评分标准

按住评分项左侧「⋮⋮」可拖动调整顺序，拖到其他分组内即移动到该分组；「序号」是评分项的身份标识，拖动后不变。
分组与评分项由你设置。点「保存」时系统会自动逐项拆解你写的评分标准文字（时间窗口／金额门槛／单项分／封顶／关键词），在下方列出解析结果并写入「评分标准_解读.json」，用于检查标准是否写得足够结构化。此解析不参与打分。

招标文件

支持 .doc / .docx / .md / .pdf。点「保存」把文件归档到「当前项目 \ 招标文件」并抽取全文与表格；点「校验标准」用该招标文件核对你的评分的评分标准（名称、分值、合计是否对得上）。
注意：.doc 是旧格式，只能近似抽取（表格结构会丢），建议用 Word/WPS 另存为 .docx 再上传。

投标文件

支持 .doc / .docx / .pdf。按「投标单位」分文件夹存放：项目\{项目名}\投标文件\{投标单位}\。点「保存」即归档到该项目该单位下。
注意：.doc 只能近似抽取（表格会压平成文字）， 涉及业绩表/获奖表时建议另存为 .docx。

评分结果

「自检」只查投标文件里关键材料是否齐备（业绩表/获奖表/工法/人员配备/简历/证书），不给分。「开始复核」才是把任务提交给 agent，由 agent 逐项判定打分。
OCR 识别 勾选需要识别的文件（默认全选）；未勾选的文件不识别，复核时只读文字层

专家打分对比 商务部分均为客观分，导入一名专家的打分表即可

导入后由 AI 解析打分表（复杂版式、扫描件也能读），解析完成自动与系统复核结果逐项比对。
